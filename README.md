# GameBacklog v4.0 — Qt Deck

Компактний список ігор, які хочеш пройти. **PySide6 / Qt** — справжня антиаліація,
High-DPI, плавні hover-анімації й сучасний вигляд за референсами Epic / Playnite / Raycast.
Ігри додаються **тільки** з Steam або з встановлених на ПК — ручного створення немає.

## Запуск / Run

Подвійний клік по `Запуск.bat` або в консолі:

```
py -m pip install PySide6
py game_backlog_qt.py
```

Потрібен **Python 3.10+** для Windows: https://www.python.org/downloads/

## Що нового у v4.0 / What's new

- **PySide6 замість Tkinter** — текст і картки малює Qt з антиаліацією, без «піксельного» ефекту.
- High-DPI працює нативно (125/150/175%+), без ручних `SetProcessDpiAwareness`.
- Кастомні QPainter-картки: радіус 8px, чіпи 4px, плавний hover за 120–140 мс.
- Без(table look), синіх ліній, тіней і пунктирних рамок фокусу.
- Збережені всі дані й логіка v2.1+: Steam/PC-сканери, пошук, імпорт/експорт,
  налаштування, глобальна гаряча клавіша, бокова вкладка `game`, RU/EN.
- Порожні слоти прибрані — залишився лише текст-підказка.
- Новий редактор: закривна панель, вертикальні статуси зі своїми кольорами,
  запуск Steam/`.exe` і оригінальні обкладинки Steam із локальним кешем.

- власні кнопки з векторними іконками й повними підписами (Steam, PC, Правка, …);
- **одна** кнопка налаштувань у лівому рейлі: векторна іконка + підпис «Настройки»;
- картки гри як міні-обкладинки: ініціали, платформа, статусна точка, теги,
  векторні hover-дії (олівець / галочка);
- фон список ігор має окремий мотив для теми: Класика/Світла — обірвані неонові
  дроти з іскрою, Дота 2 — річка Radiant/Dire й руни, Кіберпанк — data rain
  і глітч-смуги;
- список ігор — **сітка великих обкладинок** (3–4 у ряд), а не рядки-таблиця;
- у шапці — коротка назва `GameBacklog` без прямокутника фону, векторні кнопки вікна
  й пасхалка теми (щит Aegis для Доти 2, штрихкод для Кіберпанка);
- права detail-панель із оригінальною обкладинкою, вертикальними статусними рядками
  з векторними іконками й полями редагування (без плашки під міні-іконкою);
- статистика bento-картками без витрат/грошей;
- компактний неоновий док `game` справа (30×104): підсвічені кути, вертикальний
  напис, внутрішні напрямні й статусна точка; завжди поверх інших вікон, без різкої обводки.

Мова **RU / EN** перемикається кнопкою `RU/EN` або в налаштуваннях.
Усі налаштування зберігаються в `%APPDATA%\GameBacklog\settings.json`.
Налаштування застосовуються **одразу**: кнопки «Применить» немає, досить закрити вікно.

## Кнопки / Toolbar

| Кнопка (векторна іконка + підпис) | Що робить |
|---|---|
| `Steam` | Пошук гри в каталозі Steam |
| `PC` | Сканування встановлених ігор |
| `Удалить / Delete` | Видалити вибрану гру (стильний HUD-діалог) |
| `Импорт / Экспорт` | Імпорт / експорт JSON або CSV |
| `Свернуть / Compact` | Згорнути у вкладку `game` |

Мову й тему перемикаємо тільки в Налаштуваннях — на панелі цих кнопок більше немає.
Підказок при наведенні (tooltip) теж немає — зайвий текст не з’являється.
Редактор відкривається кліком по картці, окрема кнопка `Правка / Edit` не потрібна.
Зміни теми/кольорів/шрифтів застосовуються на місці, без миготіння й пересоздання вікна.

У вкладці «Кнопки» є живе прев'ю панелі, перетаскування рядків мишкою,
векторне «око» для показу/приховування, пресети «Мінімум / Звичайно / Всё»
і скидання. Стрілки залишились як запасний варіант.

## Вибір гри / Picker

Замість таблиць — картки-тайли з плавним hover:

- у вікні **Steam** введи назву — результати з офіційного каталогу Steam разом
  з їхніми обкладинками; якщо пошук нічого не знайшов, автоматично показується
  топ чарт Steam (публічний `featuredcategories`, без ключів);
- у вікні **PC** побачиш знайдені ігри (або обери папку вручну) — для Steam-ігор
  з кешу теж показується обкладинка;
- клік по картці перемикає вибір, можна відмітити кілька ігор одразу;
- зліва внизу «Выбрано / Selected: N», справа — `＋ Добавить / Add`;
- після додавання жодне вікно-сповіщення не вискакує — результат одразу видно в бібліотеці.

## Редактор гри / Game editor

- **Вигляд:** едина колонка м'яких HUD-секцій (`Основное / Статус / Запуск / Оценка
  и время / Даты и заметки`) замість сітки полів. Підписів над полями немає — лише
  placeholder усередині, рамки замінені підсвіченими панелями з кутовими засечками.
- **При запуску:** редактор вимкнено — картки займають всю ширину.
- **Без вибору:** поки карточку не натиснуто, полів введення взагалі немає.
  Поля з’являються після кліку по картці.
- **Закриття:** `×` у шапці редактора ховає панель, картки розтягуються на всю ширину.
  Знову відкрити — кліком по будь-якій картці гри. Окремої кнопки `Правка / Edit` немає.
- **Статуси:** п'ять базових (Хочу / В процесі / Пройдено / Відкладено / Кинуто)
  у вигляді вертикальних рядків із векторними іконками замість рядка чіпів.
- **Свої статуси:** кнопка `+ Свой статус` додає глобальний статус для всіх ігор.
  Правий клік по кастомному статусу — перейменувати, змінити колір або видалити
  (з підтвердженням; гри з ним повертаються у «Хочу пройти»).
- **Запуск:** `▶ Запустить` відкриває Steam-гру через `steam://rungameid/<AppID>`
  або запускає локальний `.exe` з поля `Путь к .exe` (кнопка `Обзор…`).
- **Іконка:** для Steam-ігор береться справжній `header_image` і кешується в
  `%APPDATA%\GameBacklog\icons\<AppID>.jpg`. Обкладинки підтягуються автоматично при старті,
  а також одразу після додавання, імпорту або збереження гри — чекати перезапуску не треба.
  Кнопка `Обновить иконку` оновлює вибрану гру вручну. Для ігор без Steam AppID джерела
  обкладинки немає, тому залишаються ініціали.

## Статистика / Stats

Щоб статистику не можна було «накрутити» звичайним редагуванням JSON:

- для Steam-ігор жанри беруться **тільки з публічного Steam API**
  (`appdetails`) і зберігаються в `verified_genres`; ручне поле «Жанр» у редакторі
  на статистику не впливає;
- у редакторі під полями є підпис `Данные Steam подтверждены` /
  `Ожидание проверки Steam…` / `Нет Steam AppID`;
- на вкладці статистики є окремі лічильники `Проверено Steam` і `Без проверки`;
- ручні години й оцінка **не беруть участі** в «чесних» цифрах — вони лишаються
  в картці/редакторі як особисті нотатки;
- якщо змінити `AppID`/посилання в редакторі — позначка перевірки знімається,
  і дані знову підтягуються з Steam.

Повністю заборонити редагування локального JSON неможливо, але підміна жанрів
тепер не змінює статистику: вона рахується з перевірених даних Steam.

## Налаштування / Settings

Кнопка «Настройки» у лівому рейлі (або правий клік по `game`) перемикає сторінку
всередині того самого вікна — як Статистика, без нового вікна. Всередині — п'ять розділів:

| Розділ | Що можна змінити |
|---|---|
| Тема / Theme | готові палітри: **Класика / Дота 2 / Кіберпанк / Світла** |
| Цвета / Colors | колір фону, панелей, полів, тексту, акцентів, шапки, карток, статусів, вкладки `game` |
| Шрифты / Fonts | сімейство, розмір звичайного й заголовків, свої `.ttf` / `.otf` |
| Кнопки / Buttons | прев'ю, drag&drop, око, пресети «Мінімум / Звичайно / Всё», скидання |
| Общее / General | мова, показ вкладки `game`, край/положення/дзеркало іконки й тексту, автозапуск з Windows |

### Теми / Themes

- **Класика** — поточний neon-cyber HUD: `#0b0d18`, `#8654ff`, `#4d8dff`.
- **Дота 2** — головні кольори **червоний `#BF2E1A` + чорний `#0A0708`**;
  золото Radiant `#E7A34B` лишається другорядним акцентом. На фоні —
  діагональна річка Radiant/Dire з рунами замість дротів, у картках — червона палітра,
  у шапці — щит **Aegis**.
- **Кіберпанк** — Night City: жовтий `#FCEE0A`, ціан `#00F0FF`, кримсон `#FF003C`;
  сканлайни + vertical data rain із глітч-смугами замість дротів, у шапці — штрихкод.
- **Світла** — запасний світлий режим.

Картки тем великі й розтягуються на всю ширину вкладки; у кожній — назва,
опис і чотири кольори палітри. Клік по картці міняє всю паліту одразу,
без кнопки «Применить». Кольори з розділу «Цвета» мають пріоритет над кольорами теми.

## Компактний режим / Compact mode

- За замовчуванням праворуч на екрані — вкладка з написом **game** (вертикально).
- У `Налаштування → Общее` можна вибрати край (ліворуч/праворуч/вгору/внизу),
  положення вздовж краю повзунком, дзеркалити декоративну іконку й окремо текст `GAME`.
- Клік — згорнути/розгорнути вікно. Правий клік — розгорнути, сховати вкладку,
  налаштування або вихід.
- **Ctrl+Alt+G** — те саме з клавіатури (через `RegisterHotKey`).
- Якщо вкладку сховано через «Скрыть вкладку»: `Налаштування → Общее →
  Показывать вкладку «game»` — вона повернеться одразу.

## Можливості / Features

- Статуси: Хочу пройти / В процесі / Пройдено / Відкладено / Кинуто + свої глобальні статуси.
- Пошук, фільтри за статусом/платформою, **Только активные**, сортування, власний порядок.
- Статистика без витрат: відсоток завершення, перевірені Steam-ігри й жанри, топ платформ.
- Автозапуск з Windows (галочка в `Общее`) пише команду тільки в `HKCU\...\Run`.
- Довідка / Help і Налаштування / Settings — сторінки всередині вікна, як Статистика;
  нові вікна не відкриваються. Підказки при наведенні (tooltip) вимкнені скрізь.
- Імпорт/експорт JSON і CSV (CSV у UTF-8 з BOM — відкривається в Excel).
- Автозбереження в `%APPDATA%\GameBacklog\games.json`.

## Для GitHub / Repo notes

- Залежність одна: `PySide6` (встановлюється через pip). API-ключів і секретів немає.
- Steam використовує публічні endpoints `store.steampowered.com`.
- Користувацькі дані лежать у `%APPDATA%\GameBacklog`, а не в репозиторії.
- `.gitignore` виключає `__pycache__/`, `*.pyc`, локальні `games.json` / `settings.json` і логи.
- Перед комітом: `py -m py_compile game_backlog_qt.py backlog_core.py`.
- Готовий `.exe`: `dist\GameBacklog.exe` (~46 МБ, onefile, без консолі, з іконкою `icon.ico`).
- Збірка: `py -m pip install pyinstaller` →
  `py -m PyInstaller --noconfirm --clean --onefile --windowed --name GameBacklog --icon icon.ico --add-data "icon.ico;." game_backlog_qt.py`.
- Іконка для репозиторію/window: `icon.png`, для Windows/exe: `icon.ico`.
